# Hi, I'm Ondrej Nebus

Computer Science student at **FIIT STU** in Bratislava. I like building things end
to end: smart contracts and web frontends, network protocols, databases, and data
analysis.

## Featured projects

### [PredictionDuel](https://github.com/ondrejnebus/PredictionDuel)

On-chain prediction duels with escrowed stakes, an appeal flow and on-chain
reputation. Solidity contracts tested with Hardhat, plus a Next.js frontend.
Deployed on Sepolia and live at [xebus.xyz](https://www.xebus.xyz/).

`Solidity` `TypeScript` `Hardhat` `Next.js` `Tailwind CSS`

### [LSTM Time-Series Classifier](https://github.com/ondrejnebus-coder/timeseries-lstm)

Next-day direction classification for LTC/USDT with an LSTM over real returns and
forecasts from five time-series foundation models. Also includes a from-scratch
NumPy backpropagation library with AND/OR/XOR experiments.

`Python` `PyTorch` `LSTM` `pandas` `Matplotlib`

### [OS Memory Manager](https://github.com/ondrejnebus-coder/os-memory-manager)

A paging-based memory manager in C: bitmap frame allocator, MMU permission checks,
local NRU page replacement with dirty-page write-back, and a task manager.

`C` `Operating systems` `Paging` `MMU` `Make`

### [Data Structures in C](https://github.com/ondrejnebus-coder/dsa-c)

Red-black tree, treap, double-hashing hash table and BDD in C, with an interactive
CLI, file-replay mode and a benchmark report.

`C` `Data structures` `Algorithms` `BDD` `CMake`

### [TSP Optimization](https://github.com/ondrejnebus-coder/tsp-optimization)

Tabu search and simulated annealing for the Travelling Salesman Problem, with
2-opt and segment-shuffle neighbourhoods plus live convergence plots.

`Python` `Metaheuristics` `Tabu search` `Simulated annealing` `Matplotlib`

### [Incremental k-NN](https://github.com/ondrejnebus-coder/incremental-knn)

Incremental k-NN classifier for 40,000 2D points, accelerated with a uniform grid.
Compares k = 1, 3, 7 and 15 with confusion matrices and decision surfaces.

`Python` `NumPy` `k-NN` `Spatial indexing` `Matplotlib`

### [PKS Sensor Network](https://github.com/ondrejnebus-coder/pks-sensor-network)

A UDP/JSON protocol for IoT weather stations: registration, CRC32 validation,
ACKs, retransmission and keep-alive handling, with a menu-driven multi-sensor
simulator.

`Python` `UDP` `JSON` `CRC32` `Sockets` `Threading`

### [JavaFX Card Game](https://github.com/ondrejnebus-coder/java-card-game)

A card battle game with three hero classes, enemy tiers, deck building, a shop and
save/load. Built with JavaFX and an MVC-style split between game logic and UI.

`Java 21` `JavaFX` `OOP` `Serialization`

### [Reservation System Database](https://github.com/ondrejnebus-coder/sql-reservation-system)

A PostgreSQL schema for a multi-branch reservation business, with roles,
permissions, schedules, reservations, payments, indexes and CTE-based operations.

`PostgreSQL` `SQL` `Python` `psycopg2` `PlantUML`

### [IAU Data Analysis](https://github.com/ondrejnebus-coder/iau-data-analysis)

Exploratory analysis of an IoT/APU measurement dataset: data quality, missing
values, distributions and relationships between readings, units and gateways.

`Python` `Jupyter` `pandas` `NumPy` `matplotlib` `seaborn`

### [PRPR C Exercises](https://github.com/ondrejnebus-coder/prpr-c)

C exercises covering input, loops, arrays, functions, pointers and file I/O, plus a
file-processing project that parses passenger lists and prints character histograms.

`C` `GCC` `Pointers` `File I/O`
